Budgets

Limits per project and/or agent for the current UTC day or month. Hard budgets refuse a call before it is made if its worst case would exceed the limit (HTTP 429, nothing is sent to the provider). Soft budgets only warn. USD limits count only calls on models with a price; token limits count everything.

Add or change a budget (same project + agent + period replaces the old one; leave project and agent empty for everything)

Shadow evaluation

Shadow calls cost real money, never exceed the monthly cap, and are recorded under project modelspend-shadow. Prompts are held in memory only; only verdicts and counts are stored. Requests marked sensitive are never shadowed unless you allow it. To let routing use the results, run modelspend shadow apply (it shows what would change first).
